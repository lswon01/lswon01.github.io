2. 채용공고 데이터베이스 · 시범

첨부 MVP에 수록된 공고 8건입니다. 확인일은 제공 자료의 기재일이며 운영자가 원문을 재검증한 날짜는 아닙니다. 현재 모집 여부와 조건은 고용24 원문에서 확인해 주세요.

기업직무임금필수·우대조건지역확인일원문

※ 전체 시장을 대표하는 통계가 아닙니다. 지원 전 원문에서 모집상태와 조건을 다시 확인해야 합니다.

3. 경력매칭 분석표

희망역할 20점·연봉 20점·지역 15점·경험 키워드 45점. 경력과 필수조건은 별도 확인 항목입니다. 확인 필요 항목에는 점수를 주지 않습니다. 총 제조업 경력은 해당 직무 경력의 증명이 아니며 점수는 채용 확률이 아닙니다. 산업·성과·자격은 키워드 참고자료이며 별도 확인이 필요합니다.
